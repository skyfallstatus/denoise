Denoise

Start with Natural. Check faces, fine texture and moving edges. The main panel has six controls; the others are in Advanced. Inactive controls keep their saved values and keyframes.

Look

Natural is the default. Cleaner lowers grain retention; Keep texture reduces luma cleaning; Phone also raises medium and coarse luma corrections; Colour only preserves luma. Manual changes can show Custom.

Luma reduction (dB)

Requested brightness-noise reduction: default 14 dB. 6 dB halves the removable noise left; 30 dB requests all available cleaning. The profile, grain floor and filter can limit the result.

Colour reduction (dB)

Requested colour-noise reduction, on the same dB scale. Default 30 dB. Lower it if colour detail is lost.

Keep grain (10-bit)

Retains existing fine luma grain; does not add grain. Default 0.657, displayed as 0.66, in video-range 10-bit code RMS (876 codes from black to white). Zero removes the floor.

View

Result, Removed noise, Motion protection, Measured areas, or Before / after split. Removed noise amplifies the difference. The selected view also exports; return to Result for normal output.

Advanced

Noise threshold (dB)

Single-frame noise threshold relative to the profile. Zero is neutral. Positive values smooth more; negative values preserve more texture. Typing -18 dB disables this stage.

Frames used

1, 3, 5, 7, 9 or 11 frames, including the current frame. Default 5. Motion and clip boundaries can exclude neighbours. Version 2 measures up to five nearby frames independently of this setting.

Quality

Auto follows the host quality request; ambiguous high-quality requests use Full. Fast reduces processing cost and detail, including exports. Full also enables medium-scale sharpening.

Profile

Automatic adapts as frames render. Version 2 scans the current frame and up to two available frames on each side initially. Use captured reads the profile saved in the effect; without a valid capture it falls back to Automatic.

Capture profile

Click to collect nearby full-resolution progressive frames. Play or scrub to collect at least three usable distinct frames. When Ready appears, click again to save the profile in the project.

Capture status / Refresh

Refresh reports collection progress or saved-profile fit. Collection is temporary until saved. Remeasure after changing the source, exposure, raster or upstream colour.

Freeze (this session)

Holds the settled automatic profile for this session. It is not saved; a restart can measure again. Inactive with a valid captured profile.

Profile correction (dB)

Shifts all measured noise levels. Zero is neutral; +6 dB doubles sigma and -6 dB halves it. Global, channel and scale corrections add in dB.

Motion threshold (dB)

Neighbour mismatch threshold. Lower values reject more motion and can leave more noise. Inactive with one frame.

Edge ghost protection

Extends coarse motion rejection into nearby detail. Higher protection can reduce trails and leave more noise around moving edges.

Reduction limits by size

Caps luma or colour reduction at fine (1–2 px), medium (2–4 px), coarse (4–8 px) or large (8+ px) scales. The bands overlap. Default 30 dB adds no limit; 6 dB retains half the removable noise at that scale.

Channel and scale corrections

Adjust measured sigma for luma, Cb, Cr or a scale band. Zero dB is neutral. Positive values treat more variation as noise and can remove texture.

Remove specks

Treats isolated noise excursions as specks. On by default. Turn off to compare small lights, stars or sparkle.

Sharpen

Adds luma edge contrast after cleaning. Zero disables sharpening. It cannot restore removed detail.

Sharpen fine

Relative gain for roughly 1–2 pixel detail; 100% is neutral.

Sharpen medium

Relative gain for roughly 2–4 pixel detail; 100% is neutral. Requires Full quality.

Sharpen threshold (dB)

Coring threshold above remaining noise. Zero dB is neutral; positive values protect more weak detail from sharpening.

Sharpen halo limit

Limits bright and dark overshoot around sharpened edges.

Keep grain applies to

Finest grain only retains the finest octave. Whole picture preserves the earlier grain-floor and profile aggregation. Saved projects retain their choice.

Processing

Version 1 preserves earlier processing. Version 2 adds collapsed-chroma profile recovery and measured temporal residual noise. Looks and control-unit changes leave this choice unchanged.

Grain stability

Stabilizes retained luma grain using nearby frames. Off by default. Can reduce fine detail; requires temporal and spatial filtering.

Coarse colour cleanup

Additional qualified coarse-colour cleanup. Off by default.

Switch to dB controls

Converts eligible previous controls to dB units while preserving their meaning. Animated controls can prevent conversion.

Previous controls (old projects)

Older projects retain their original controls and values. Luma and colour amounts use percent, Minimum grain is a floor multiplier, Frames each side is the neighbour radius, and Noise level is a sigma multiplier.
